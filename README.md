# Kitty Care 🐾

Een spelletje in de browser waarin je voor je eigen kat zorgt. Werkt op iPhone, iPad, Android en computer.

## Zo speel je
- **Verzorgen**: geef je kat eten, water, snoepjes, speel, borstel, was, maak de kattenbak schoon en laat je kat slapen. Tik op de kat om te aaien.
- **Levels**: elk level heeft zorg-uitdagingen. Heb je alle taken gehaald, dan krijg je munten en ga je naar het volgende level. Na level 10 krijg je steeds nieuwe uitdagingen.
- **Minigames** (munten verdienen):
  - 🧮 Snel Rekenen – sommen oplossen tegen de klok
  - 🌳 Boom Klimmen – klim zo hoog mogelijk, ontwijk de takken
  - 🧩 Kattenpuzzel – zoek alle paartjes
  - 🐭 Muizen Vangen – tik de muizen, niet de hond!
- **Winkel**: koop voer en verzorging, speelgoed, meubels voor het kattenhuis, kleding voor je kat en nieuw behang.
- Let op de balkjes! Als je kat te lang honger, dorst of een vieze kattenbak heeft, wordt hij ziek. Dan helpt medicijn of de dokter.

Je voortgang wordt automatisch bewaard in de browser.

## Online zetten met GitHub Pages
1. Ga op GitHub naar de repository → **Settings** → **Pages**.
2. Kies bij *Source*: **Deploy from a branch**, kies de branch en map **/ (root)**, klik **Save**.
3. Na ±1 minuut staat het spel op `https://<gebruikersnaam>.github.io/<repository>/`.

### Op je iPhone
Open de link in Safari → tik op **Deel** (vierkantje met pijl) → **Zet op beginscherm**. Dan heb je een eigen Kitty Care-app op je telefoon, zonder balken van de browser.

## Techniek
Gewone HTML, CSS en JavaScript – geen installatie of build nodig. Open `index.html` of start een lokale server (`npx http-server`).
